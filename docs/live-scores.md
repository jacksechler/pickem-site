# CBS Sports live scores

Members can open **Live game scores** on Home, see the current game in My picks, or follow connected games in GameDay. Scores, team names, clocks and statuses come directly from CBS Sports. Game links also open CBS Sports. Logos use CBS's image host and fall back to team abbreviations if that host is unavailable. Displayed times use each member's local time; the commissioner's game date selector explicitly uses Eastern time.

In **Commissioner → Week setup → Connect live scores**, choose **Find matching games**, review the matchups, then connect them. Only a unique match for both team names is suggested. The manual picker supports a specific NFL, CFB or men's CBB game. CFB includes regular season, bowls and CFP; CBB includes all available games on the selected day. Connections can be changed before the week is published.

Connections live in the existing `questions.team_meta.live_score` JSON object: `provider: "cbs"`, numeric-string `id`, `league`, Eastern `day`, and `sourcePage`. Updates preserve other team metadata and use existing commissioner RLS. Legacy ESPN fields remain unused; the live-score feature makes no ESPN requests. No database migration, API key or server proxy is required.

The adapter fetches public CBS scoreboard HTML with omitted credentials, then decodes its embedded JSON as data. It never evaluates page scripts, embeds a page, imports vendor JavaScript or uses the vendor's authenticated live service. It retains only ordinary game identifiers, teams, scores, schedule and status. Scores remain informational: it never writes official answers, pick results, result order, points, deadlines or postseason state.

Public CBS scoreboards are not a contracted API. Their HTML and cross-origin access may change. A failed response retains the last successful score with an update-delayed label. NFL and CFB use weekly scoreboards; CBB uses daily pages. The adapter maps the season calendar to those routes, including the Wednesday opener, bowls, NFL playoffs and the extended semifinal round. A missing event is checked on the current CBS scoreboard by its stable numeric ID. If it is still missing, its last known score is marked delayed; the commissioner can reconnect it if the provider changes its ID.

The UI checks every 30 seconds while visible. Active scores are cached for 30 seconds and other schedules for two minutes; CBS's own updates may be delayed. Connected games share a source-page request, and daily searches use at most three requests at a time. Hidden tabs and collapsed Home scores stop polling. Navigation cancels requests, and late responses cannot repaint another week.

Verification: `node --test tests/live_scores.test.cjs tests/gameday_model.test.cjs` and `node tests/release_check.mjs`. Sanitized public-data fixtures cover NFL, CFB and CBB. Tests cover parsing without script execution, score states, safe URLs, exact matches, metadata preservation, postseason routes, caching, missing games and cancellation. Public source routes and cross-origin headers were checked directly; actual league Wi-Fi must be checked from a member's device. No browser QA was requested.
